# Changelog

## 0.1.0 — 2026-09-12

First public preview for the VSD N4 Pro on Arch Linux / Omarchy.

- Native Qt editor for ten display keys, four touch zones, four knobs, and swipes.
- Custom images, labels, colors, brightness, profiles, and tray operation.
- Program launching, websites, keyboard shortcuts, playback, and PipeWire audio.
- Live CPU, memory, filesystem, and optional Open-Meteo weather tiles.
- Editable DaVinci Resolve keyboard shortcut profile with a Hyprland focus check.
- SDK-based USB transport, reconnect, and real HID permission checks.
- Simulator and 68 automated tests.

The physical device's labels and monitor tiles were confirmed working on an
N4 Pro reporting USB ID `5548:1023`. Other listed variants have not been tested
on hardware. This is an early release; Resolve plugin parity is not included.
